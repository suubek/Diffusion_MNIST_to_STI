# Using Diffusion for STI Image Generation
This project uses Calzaretta's Diffusion Model, primarily DDPM, and adapted to fit STI dataset. STI data is not publicly available.

For further detail on model specifications, refer to Calzaretta's [Blog](https://medium.com/@j.calzaretta.ai/exploring-diffusion-models-a-hands-on-approach-with-mnist-baf79aa4d195) where they go indepth of model details.
